# Airline Management System (Stack Based)

This project is a simple **Airline Management System** implemented in Python using the **Stack (DSA concept)**.  
It allows users to:
- Book a ticket (push operation)
- Cancel a ticket (pop operation)
- View passenger list
- Assign seat numbers

## Features
- Stack-based booking system
- Auto seat number assignment
- Simple text-based interface
- Can be extended with a frontend (Tkinter or Flask)

## Project Structure
- `airline_stack.py` → Main source code
- `README.md` → Project documentation
